Firebase Firestore avviser forespørselen – endringer oppdateres IKKE på telefonen din før dette er åpnet!

Telefonen din og PC-en din er på to forskjellige enheter, så de må kunne snakke med Firebase i skyen.

Slik fikser du dette på 1 minutt i Firebase Console:

  1. Gå til Firebase Console: console.firebase.google.com/project/smaksync/firestore
  2. Dersom databasen ikke er opprettet ennå: Klikk «Create database».
  3. Klikk på fanen «Rules» (Regler), erstatt innholdet med dette og trykk «Publish»:
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}
Når reglene er publisert, forsvinner denne meldingen automatisk.
