Firebase Firestore Konfigurasjon

Hvordan koble til ditt eget Google Cloud / Firebase prosjekt

Koden benytter Firebase v9 Modular SDK via CDN. For å koble direkte til din egen database:

  1. Gå til console.firebase.google.com
  2. Opprett et prosjekt og aktiver Firestore Database
  3. Gå til Project Settings → General → Your apps → Web app
  4. Lim inn din firebaseConfig i toppen av scriptet i superadmin.html, admin.html og meny.html
